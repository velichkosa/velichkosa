# АСПО.Контроль

> Система мониторинга и оптимизации операций по скребкованию скважин

---

<details>
<summary>🇷🇺 Русский</summary>

### 🚀 Обзор

АСПО.Контроль — это система анализа и контроля процессов скребкования скважин на основе фактических данных.

Сервис обрабатывает данные из электронных систем контроля, определяет характер отложений и помогает оптимизировать
планирование работ.

---

### 💡 Проблема

- отсутствие достоверных данных по отложениям
- зависимость от отчетов подрядчиков
- лишние обработки скважин
- высокие затраты и неэффективность

---

### ✅ Решение

Система, которая:

- загружает данные из ЭСК
- автоматически анализирует отложения
- классифицирует скважины
- проверяет корректность данных подрядчиков
- помогает принимать решения

---

### 🧩 Возможности

- импорт и обработка данных
- автоматическая классификация скважин
- интерактивные таблицы и графики
- формирование отчетов
- рассылка
- экспорт в Excel

---

### ⚙️ Технологии

**Backend:**  
Python, Django DRF, Dramatiq

**Frontend:**  
React, TypeScript

**Данные:**  
PostgreSQL, Redis

---

### Результат

- сокращение затрат
- оптимизация процессов
- снижение трудозатрат
- повышение точности данных
- улучшение планирования

### 🚀 Overview

ASPO Monitoring System is an internal platform for analyzing and controlling well scraping operations based on real
operational data.

The system processes data from electronic control systems, evaluates the presence and severity of deposits, and helps
optimize maintenance planning.

---

### 💡 Problem

- lack of reliable data on actual deposit conditions
- dependence on contractor-reported information
- unnecessary scraping operations
- high operational costs and inefficiencies

---

### ✅ Solution

A data-driven monitoring system that:

- imports data from electronic control systems (ESC)
- automatically analyzes deposit characteristics
- classifies wells based on severity
- validates contractor-reported data
- supports decision-making for operation planning

---

### 🧩 Key Features

- data import and processing
- automated classification of wells
- interactive dashboards (charts, tables)
- reporting and notifications
- export to Excel

---

### ⚙️ Tech Stack

**Backend:**  
Python, Django DRF, Dramatiq

**Frontend:**  
React, TypeScript

**Data:**  
PostgreSQL, Redis

---

### Value

- reduction of unnecessary well treatments
- improved decision-making accuracy
- validation of contractor data
- cost optimization
- reduced manual workload
